# OrionLabs Headline Style Audit

## Scope and Final System

This document records the final approved treatment for the 16 authored major display headlines on the landing page, static Report header, Legal, Docs, Press, and four research-paper routes. Questionnaire, Review Answers, Analysis/Calibration, generated Report content, and all smaller headings remain outside scope.

1. **Gradient gold is the default** across each display headline.
2. **Pink is semantic emphasis** for the exact approved phrase only.
3. **Pink is the sole emphasis treatment**; display-headline emphasis does not use italics.
4. **White is not an emphasis treatment** in this display-headline system.
